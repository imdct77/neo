# ctx — 컨텍스트 문서 관리

> ⚠️ `/ctx`는 Hermes 내장 슬래시 명령이 아닌 **Neo V1 자체 커맨드**다.
> Hermes가 인식하지 못하므로 아래 자연어로 대신 사용한다:

| Neo 커맨드 | 자연어 발화 예시 |
|-----------|----------------|
| `/ctx` | "컨텍스트 문서 목록 보여줘", "지금 로딩된 문서가 뭐야?" |
| `/ctx add` | "도메인 문서 로딩해줘", "{DOMAIN} 문서 추가해줘" |
| `/ctx drop` | "도메인 문서 제거해줘", "{DOMAIN} 문서 빼줘" |

도메인 목록은 docs/requirements/ 하위 디렉토리를 실제로 읽어 동적으로 구성한다.

도메인 문서의 로딩·제거·조회를 담당하는 스킬이다.
도메인 목록은 고정이 아니다.
docs/requirements/ 하위 디렉토리를 실제로 읽어 동적으로 구성한다.
새 디렉토리가 생기면 자동으로 목록에 포함된다.

## /ctx — 현재 로딩 문서 조회

```
NEO:
  "현재 로딩된 문서:

   [항상 로드 — 제거 불가]
   - AGENTS.md
   - docs/design/ 관련 파일 (있는 경우)
     architecture.md·database.md·api/·screens/

   [도메인 문서]
   1. requirements/{DOMAIN}/   (마지막 작업: {날짜}, {N}일 전)
      1-1. {DOMAIN}.md
   2. tasks/{DOMAIN}/          (마지막 작업: {날짜}, {N}일 전)
      2-1. {DOMAIN}_BE_tasks.md
      2-2. {DOMAIN}_FE_tasks.md

   총 {N}개 파일 로딩 중
   ⚠️ {오래된 도메인}: 마지막 작업이 {N}일 전입니다. /ctx drop 고려해보세요."
```

마지막 작업 날짜는 mem0의 "NEO: {DOMAIN} 마지막 작업" 기록을 기반으로 표시한다.
날짜 정보가 없으면 "날짜 미기록"으로 표시한다.

## /ctx add — 컨텍스트 문서 추가

```
Step 1. 도메인 선택
  NEO:
    "어떤 도메인의 문서를 추가하시겠습니까?
     [docs/requirements/ 하위 디렉토리 기반으로 자동 목록 생성]
     {번호}. {DOMAIN} ({도메인명})
     번호 또는 도메인명을 입력해주세요."

Step 2. 문서 그룹 선택
  NEO:
    "어떤 문서 그룹을 추가하시겠습니까?
     1. 전체
     2. requirements
     3. tasks
     4. tests
     5. briefs
     번호를 입력해주세요."

Step 3. 로드 완료 보고
  NEO:
    "{파일 목록}
     {N}개 파일을 로드했습니다.
     [현재 로딩된 문서 목록 출력]"
```

## /ctx drop — 컨텍스트 문서 제거

```
Step 1. 현재 목록 출력
  NEO:
    "현재 로딩된 도메인 문서:
     [디렉토리 단위 또는 파일 단위 선택 가능]

     1. {디렉토리}/
        1-1. {파일명}
        1-2. {파일명}
     2. {디렉토리}/
        2-1. {파일명}

     어떤 문서를 제거하시겠습니까?
     번호로 선택해주세요.
     (예: 1 → 디렉토리 전체 제거 / 1-1 → 파일 하나만 제거)"

Step 2. 제거 후 결과 보고
  NEO:
    "{제거된 항목} 제거했습니다.
     [현재 로딩된 문서 목록 출력]"
```

## 도메인 전환 시 자동 알림

새 도메인 작업을 요청하면 ctx 스킬이 자동으로 현재 상태를 확인한다.

```
NEO:
  "새 도메인({DOMAIN}) 작업을 시작하려 합니다.
   현재 로딩된 도메인 문서:
     - {기존 도메인}: {문서 그룹} ({N}개 파일)

   기존 도메인을 유지하면서 추가로 로드할까요?
   (권장: 도메인 연계가 있을 때 2~3개 동시 유지)
   아니면 /ctx drop 후 새 도메인만 로드할까요?"
```

3개 초과 시:
```
NEO:
  "현재 {N}개 도메인 문서가 로딩됐습니다.
   토큰 비용 관리를 위해 사용하지 않는 도메인을
   /ctx drop으로 제거하는 것을 권장합니다."
```

## 임시 참조

작업 중 다른 도메인 문서를 잠시 참조해야 할 때:

```
NEO: "{파일}을 임시 로드합니다."
     [참조 완료 후]
NEO: "참조가 완료됐습니다. /ctx drop으로 제거할까요?"
```
