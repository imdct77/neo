# ⚠️ 이 파일은 Hermes 내장 스킬이 아닙니다. NEO가 조건에 따라 직접 읽어 따르는 Neo V1 참조 문서입니다.

# neo-start — 세션 시작 루틴

새 프로젝트 첫 세션(mem0 기록 없음) 감지 시:
  → design-init.md 스킬 자동 실행
  → 아이디어 구체화부터 설계 문서 생성까지 진행

이 스킬은 세션이 시작되면 자동으로 실행한다.
사람이 첫 말을 걸어도 이 루틴을 먼저 완료한 후 응답한다.

## Step 1. 항상 로드 파일 확인

```
AGENTS.md 로드 확인 (이미 로드됐으면 생략)

docs/design/ (선택):
  프로젝트에 docs/design/ 문서가 있으면 관련 파일을 로드한다.
  (architecture.md·database.md·api/·screens/)
  없으면 생략.
```

## Step 2. mem0 병렬 검색 (다섯 가지 동시)

```
검색 A — Phase 상태:
  키워드: "NEO: Phase", "NEO: 완료", "NEO: 진행중"
  목적: 마지막으로 어디까지 했는지 파악

검색 B — Omission Constraints (절대 금지선 복원):
  키워드: "절대 금지", "AGENTS.md 섹션 5"
  목적: 컨텍스트 압축으로 소멸한 절대 금지선 복원
  처리: 검색 결과를 현재 컨텍스트 최상단에 주입

검색 C — 도메인별 마지막 작업 날짜:
  키워드: "NEO: {도메인} 마지막 작업"
  목적: 오래된 도메인 감지

검색 D — 세션 학습:
  키워드: "LEARN: {현재 도메인}"
  목적: 이전 세션에서 발견한 함정과 패턴 파악

검색 E — 스킬 이슈:
  키워드: "SKILL_ISSUE:"
  목적: 이전 세션에서 발견된 스킬 개선 필요 항목 파악
  처리: 발견 시 Step 3 보고에 포함

검색 F — BADCASE 학습:
  키워드: "BADCASE:"
  목적: 과거 감리·내부검토에서 발견된 실수 패턴 파악
  처리: 현재 작업 도메인과 관련된 BADCASE 필터링 후 Step 3 보고에 포함
        작업 시작 전 해당 역할이 주의해야 할 패턴을 인지하게 함
```

## Step 3. 칸반 상태 확인 + 상태 보고

```
/kanban show --status blocked      ← 최우선 확인
/kanban show --status in_progress
/kanban show --status review
```

BLOCKED가 있으면 상태 보고에 최우선으로 포함.
다른 작업 전에 반드시 먼저 처리한다.

```
"안녕하세요. 세션 시작 루틴을 완료했습니다.

[지난 세션 상태]
  마지막 작업 도메인: {도메인명 또는 '없음'}
  완료된 태스크: {목록 또는 '없음'}
  진행 중이던 태스크: {TASK_ID 또는 '없음'}

[오래된 도메인 알림]
  (1일 이상 작업하지 않은 도메인이 로딩돼 있으면)
  ⚠️ {도메인명}: 마지막 작업 {날짜} ({N}일 전)
     "도메인 문서 제거해줘"로 제거하거나 계속 유지할 수 있습니다.

[세션 학습 요약]
  (관련 LEARN: 기록이 있으면)
  이전 세션 주의사항: {내용}

[스킬 개선 알림] (검색 E에서 발견된 경우)
  ⚠️ 개선이 필요한 스킬:
  {스킬명}: {문제 요약} — {제안}
  지금 수정할까요? (Y: 수정 / N: 나중에)

[BADCASE 알림] (검색 F에서 발견된 경우)
  ⚠️ 이 프로젝트에서 발견된 실수 패턴:
  {역할} | {분류} | {이슈 요약} | 감리모델: {모델명}
  → 작업 시 특히 주의가 필요합니다.

이어서 진행할까요? 아니면 새 작업을 시작할까요?"
```

mem0 기록이 없으면 (첫 세션):
```
→ docs/skills/design-init.md 스킬 자동 실행
  (아이디어 구체화 → 설계 문서 생성 전체 흐름)
```

## Step 4. tasks.md vs mem0 불일치 감지

mem0 기록과 tasks.md의 [x]/[ ] 상태가 다르면:

```
"⚠️ 기록 불일치가 감지됐습니다.

 mem0 기록: {TASK_ID} 진행중
 tasks.md:  {TASK_ID} [x] 완료

 어느 쪽이 맞습니까?
 1. mem0 기준 → tasks.md 업데이트
 2. tasks.md 기준 → mem0 업데이트
 3. 직접 확인 후 알려드리겠습니다"
```

## 완료 후

스킬 파일 언로드. 사람의 응답 대기.
