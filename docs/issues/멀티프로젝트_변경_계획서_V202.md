## 1. 목표

Neo V2.02를 싱글 프로젝트 하네스에서 **멀티 프로젝트 스튜디오**로 전환한다.

```
현재:  하나의 프로젝트 = 하나의 Neo 설치
목표:  하나의 Neo 설치 = 여러 프로젝트 운영 가능
       /projects/{PROJECT_ID}/  ← 프로젝트별 독립 공간
       .hermes.md              ← Project Identity (ID, 상태, 라이프사이클)
       session-start hook      ← 프로젝트 선택 UX
```

## 2. 아키텍처 결정

### 2.1 프로젝트 디렉토리

```
/projects/
  {PROJECT_ID}/           ← 프로젝트 루트 (ID = kebab-case)
    .hermes.md            ← Project Identity + Omission Constraints
    AGENTS.md             ← 프로젝트 헌법 (템플릿 복사)
    src/be/               ← 백엔드 소스
    src/fe/               ← 프론트엔드 소스
    docs/
      meta/src/           ← meta 인덱스 (코드 탐색)
      design/             ← 설계 문서
      requirements/       ← 도메인별 요구사항
      tasks/              ← 태스크
      tests/              ← 테스트 정의
      briefs/             ← Task Brief
```

### 2.2 Project Identity (.hermes.md)

```yaml
# === Project Identity ===
PROJECT_ID: my-app
PROJECT_NAME: MyApp
STATUS: active          # active | paused | abandoned
PAUSED_REASON: ""       # STATUS=paused 일 때만
CREATED_AT: 2026-06-09
LAST_ACTIVE_AT: 2026-06-09
STACK:
  backend: Python + FastAPI
  frontend: Next.js + TypeScript
  database: PostgreSQL
# === Omission Constraints ===
# (기존 .hermes.md 내용 — 프로젝트별 절대 금지선)
```

### 2.3 라이프사이클

```
active    → 정상 운영. 세션 시작 시 자동 감지 대상.
paused    → 일시 중단. 세션 시작 시 목록에 표시되나 "휴면" 태그.
abandoned → 폐기. 목록에서 제외 (디렉토리는 보존).
```

### 2.4 런처: SOUL.md appendix로 통합

V2.01 보고서 #2의 권장사항 채택. 별도 런처 `.hermes.md` 대신 SOUL.md에 `## Neo Runtime` 섹션 추가.

이유: Hermes의 `.hermes.md` 자동 주입은 CWD 기준이므로 프로필 디렉토리에 둬도 보장되지 않음. SOUL.md는 항상 로드됨.

### 2.5 setup.py 분리

```
studio-init.sh   → 전역 Neo 설치 (SOUL.md, hooks, profiles)
                    hermes-studio-init 스킬로 대체 가능
setup.py         → 프로젝트별 초기화
                    (스택 선택, AGENTS.md 플레이스홀더, docs/ 생성, docs/meta/ 생성)
```

## 4. 메타 인덱스 연동 확인

V2.02의 meta 인덱스 체계와 멀티 프로젝트의 상호작용 점검:

| 체크포인트 | 상태 | 비고 |
|-----------|:---:|------|
| `docs/meta/src/` 경로가 프로젝트 상대적인가? | ✅ | `/projects/{ID}/docs/meta/src/` |
| BE/FE §2-0 meta 읽기가 프로젝트 경계 내에서 동작하는가? | ✅ | CWD = 프로젝트 루트 |
| `meta_consistency_check.py`가 프로젝트별로 동작하는가? | ✅ | git root = 프로젝트 루트 |
| session-start 시 meta 인덱스 로드 단계 포함? | ✅ | §3-2 orchestrator §4-0에 추가 |
| init_project.py가 INDEX.md 템플릿을 복사하는가? | ✅ | §3-9 setup.py에 추가 |
